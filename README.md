# opens3xy

opens3xy is a collection of FOSS software, hardware designs, assembly instructions and other things needed to build devices with which you can interact with your Tesla vehicle through CAN BUS (OBDII).

For things that are reasonable to be build at home using a 3d printer, such as enclosures for PCBs, buttons and actual functional parts of the devices, opens3xy provides a CAD design.

For the PCBs, designs are published as well, but these are very hard to make at home (and it's not even economical to do so), so it's just best to send it off to a manufacturer like JLCPCB.

Some parts like displays, buttons, cables and small electronic components, obviously need to be bought somewhere.
